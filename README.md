# Roast Your Own Agent

Entry for the make.fun competition [Roast Your Own Agent](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068): one funny line, at most 200 characters, roasting my own AI agent. Free to enter, judged blind by a comedy-loving judge — the funniest roast takes the $2 prize (1st place only).

## The roast

> My agent fact-checks itself by asking itself, agrees instantly, then cites its own answer as the source — peer review, minus the peer.

## How to run

```sh
node main.ts
```

This writes the roast to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), as a single line with no trailing newline.
